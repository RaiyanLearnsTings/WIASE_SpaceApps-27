# NASA_SpaceApss_27_SSS

This is Team Super Space Sages' proposal for the 2027 NASA Space Apps Challenge.

Track: Create Health Monitoring Software for Astronauts on Space Missions

Team Members:
Raiyan Bakshi (B.S Environmental Engineering and Biomedical Engineering @CMU)
Joshua Asamoah (B.S. Physics @ CMU)

Objective:
Create a health monitoring app to prevent and treat health problems


Background:

NASA’s Human Research Program has mapped the five hazards of human spaceflight: space radiation, isolation and confinement, distance from Earth, gravity fields, and hostile closed environments. 

These hazards can contribute to health problems such as immune system changes, bone density loss, cardiovascular events, inadequate nutrition, behavioral health conditions, etc. 

Some useful health indicators are blood pressure, heart rate, blood sugar, body temperature, daily sleep hours, and mood.

Data will be released Friday, 11/13/26, to which teams will have 2 days to work on it 'till Sunday 11/15.
