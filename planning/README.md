# Planning & inspiration

How WIASE was designed: the team's creative process, kept alongside the code.

| Folder | What goes here |
|---|---|
| [`sketches/`](sketches/) | Hand drawings and layout sketches. The four-page layout (dashboard, astronaut page, to-do list, cabin status) came from one of these. |
| [`palettes/`](palettes/) | Colour-palette references. The current UI uses black, crimson `#C5003C`, deep crimson `#880425`, yellow `#F3E600` and aqua `#55EAD4`; an earlier slate/orange palette came first. |
| [`notes/`](notes/) | Study notes and research on astronaut health, spaceflight risks and the datasets. |

Data sources and their licences are in [`../data/SOURCES.md`](../data/SOURCES.md).
